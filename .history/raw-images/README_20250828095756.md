# Raw Project Images

Place original source images for each project into `projects/`.

Expected filenames (match `base` keys in `src/data/projects.js`):
- studio-identity.jpg
- ecommerce-platform.jpg
- interactive-portfolio.jpg
- packaging-design.jpg

You can use .png as well. Then run:

```
pnpm optimize:images
```

This will generate hashed responsive variants (jpg/webp/avif) in `public/projects/` and update `src/data/projectImageManifest.json`.
