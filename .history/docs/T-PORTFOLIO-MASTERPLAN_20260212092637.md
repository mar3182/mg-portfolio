# T-PORTFOLIO MASTERPLAN

## 🎯 Kernvisie: De Twee Zijden

Dit portfolio is geen website — het is een **navigeerbare ruimte** die de twee werelden van deze professional onthult:

```
                    ┌──────────── BREEDTE ────────────┐
                    │                                  │
                    ▼                                  ▼
               DESIGN                             TECHNOLOGY
            (Organisch)                          (Structureel)
                 │                                    │
                 │          ╔═══════════╗             │
                 └─────────▶║ IDENTITEIT ║◀───────────┘
                            ╚═════╦═════╝
                                  ║
                            DIEPTE ▼
                           (Projecten)
```

### Het Concept
> "Dit portfolio laat niet zien wie ik ben — het laat je ontdekken hoe ik denk."

De **horizontale as** representeert breedte van denken (Design ↔ Technology)  
De **verticale as** representeert diepte van uitvoering (werk, projecten, detail)

## 🚨 Wat Moet Veranderen

### 1. De T-Vormige Navigatie is Niet Duidelijk Genoeg
Het twee-zijden concept moet visueel en interactief duidelijker zijn:
- Bij laden: portret in het midden, duidelijke visuele hints naar links (Design) en rechts (Tech)
- Horizontale beweging moet **voelbaar** de wereld verschuiven
- Verticale scroll moet pas betekenisvol worden NADAT een richting is gekozen

### 2. Assets Zijn Te Generiek
Huidige beelden zijn stockfoto-achtig of AI-generated. Dit ondermijnt authenticiteit.

### 3. Projecten Missen Diepte
De project cards zijn vlak. Ze moeten rijker storytelling hebben.

### 4. De Twee Werelden Voelen Niet Genoeg Anders
Design-kant en Tech-kant moeten visueel en atmosferisch **drastisch** verschillen.

## 🎨 NIEUWE VISUELE TAAL

### Design Wereld (Links, identity = 0)
| Aspect | Beschrijving |
|--------|-------------|
| **Kleuren** | Warme aardetinten: terracotta, amber, ivoor, zacht rood |
| **Texturen** | Papier, verf, stof, organische vormen |

### Tech Wereld (Rechts, identity = 1)
| Aspect | Beschrijving |
|--------|-------------|
| **Kleuren** | Koele tinten: cyaan, paars, donker blauw, wit |
| **Texturen** | Circuit-patronen, grid, precisie |
| **Motion** | Strak, metrisch, geometrisch, pulsend |

| **Achtergrond** | Subtiele matrix/code rain, grid overlays |
| **Decoraties** | Gloeiende nodes, verbindingslijnen, data-visualisatie |

### Neutrale Zone (Midden, identity = 0.5)
- B&W portret dominant
- Minimale decoratie
- Rustig, uitnodigend om een richting te kiezen

```
┌────────────────────────────────────────────────────────────────────────────┐

│   ┌─────────────┐                                      ┌─────────────┐    │

│   │  WORLD      │          ║               ║           │    WORLD    │    │
│   │             │◀─────────║   PORTRAIT    ║──────────▶│             │    │
│   │  (hover     │          ║               ║           │  (hover     │    │

│   │             │                  │                   │             │    │
│   └─────────────┘                  │                   └─────────────┘    │
│                                    │                                       │
│         ← Drag/Scroll Left         │         Drag/Scroll Right →          │
│                                    ▼                                       │
│                           VERTICAL DEPTH                                   │
│                         (Projects unlock)                                  │
└────────────────────────────────────────────────────────────────────────────┘
```

### Navigatie Flow
1. **Starter**: Portret centraal, subtiele pulse animatie, tekst "Explore"
2. **Horizontale Ontdekking**: Muis/touch links of rechts onthult geleidelijk de andere wereld
3. **Commitment**: Bij 30%+ naar één kant, begint die wereld te domineren
4. **Verticale Diepte**: Scrollen onthult projecten in die wereld
5. **Project Focus**: Click opent fullscreen project experience

## 💡 DIFFERENTIATIE STRATEGIE

### Wat Maakt Dit Portfolio Uniek?

1. **Navigatie als Narratief**
   > Geen menu, geen uitleg. De interface VERTELT het verhaal.

2. **Authentieke Kunstzinnigheid**
   > Elk visueel element is echt — geschilderd, gefotografeerd, getekend.
   > Geen stockfoto's, geen AI-generated assets, geen goedkope trucs.

3. **T-Shaped Metafoor**
   > De breedte EN diepte van talenten, ruimtelijk verkend.

4. **Emotionele Connectie**
   > Het portret als emotionele anker — je ontdekt een PERSOON, niet een website.

5. **Controlled Imperfection**
   > Subtiele asymmetrie, menselijke onregelmatigheid, handgemaakt gevoel.
